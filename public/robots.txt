# Every page here is public by intent, so nothing is hidden from crawlers.
# This file names the crawlers explicitly rather than relying on the wildcard,
# because 2026 answer engines (ChatGPT, Perplexity, Claude, Google AI) use
# their own user agents — and a wildcard Allow is easy for a host or CDN to
# override by accident.
#
# Two kinds of bot:
#   · retrieval bots — fetch a page to answer a question, with a citation.
#     These you always want. They are the new search traffic.
#   · training bots — crawl to train models. Allowing them is a reach
#     decision, not a ranking one; blocking them does NOT remove you from
#     AI answers. To opt out of training, change the three Allow lines under
#     "AI training crawlers" to Disallow.
# =============================================================================
